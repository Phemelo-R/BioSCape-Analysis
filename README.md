## Overview

This repository contains the full analytical pipeline developed for the study:

> **Rutlokoane, P., O'Farrell, P., & Blanchard, R.** — *Monitoring Leucadendron argenteum populations: exploring opportunities offered by emerging technologies.* JGR Biogeosciences (under review).

The Silvertree (*Leucadendron argenteum*) is a rare, silver-leaved endemic tree restricted to the Cape Peninsula of South Africa and listed as Vulnerable under the SANBI Red List. The study evaluates whether airborne remote sensing from NASA's **2023 BioSCape campaign** can support the detection and monitoring of *Leucadendron argenteum* (Silvertree) across Table Mountain National Park, South Africa.

The workflow combines:

- AVIRIS-NG Level-3 imaging spectroscopy
- LVIS Level-2 full-waveform LiDAR
- field-measured vegetation and canopy-height data
- machine-learning classification
- spectral similarity analysis
- dimensionality reduction
- wavelength contribution analysis
- AVIRIS-NG + LVIS data fusion
- landscape-scale probability mapping
- independent occurrence-based validation
- publication-quality cartography

The repository is organized as a **sequential analysis pipeline**. Each notebook represents one stage of the study, and later notebooks use files or results generated by earlier stages.

## Running the Pipeline

The three notebooks must be run **in order**. Each notebook produces outputs that are required by the next.

---

### Step 1 — Spectral Library Extraction
📁 `Spectral_Library/Phemelo-R_Spectral_Extraction.ipynb`
**Kernel: R**

This notebook builds the species spectral library from the AVIRIS-NG Level-3 tiles. It takes the field-collected GPS coordinates of 26 vegetation species and extracts the corresponding hyperspectral reflectance values directly from the imagery, one tile at a time.

**What it does:**
1. Loads field species coordinates and reprojects them into the AVIRIS Albers coordinate system
2. Reads wavelength metadata from the AVIRIS NetCDF files (425 bands, 380–2510 nm)
3. Loops through every AVIRIS tile, finds which species points fall within it, and extracts the full spectrum at each point
4. Checks and corrects reflectance scaling (converts ×10,000 integers to 0–1 float)
5. Calculates NDVI for every extracted spectrum and removes non-vegetation points (NDVI < 0.2)
6. Removes spectra where more than 50% of bands are missing
7. Saves the cleaned spectral library as `.rds` and `.csv`

**Output:** `species_spectra4.csv` — used in Step 3

---

### Step 2 — LiDAR Canopy Height Analysis
📁 `LiDAR Analysis/02–Phemelo-R_RH98_Analysis.ipynb`
**Kernel: Python**

This notebook processes the LVIS Level-2 full-waveform LiDAR data for the seven 10 m × 10 m field plots established on the slopes of Table Mountain. It extracts canopy height metrics and validates them against field-measured *L. argenteum* tree heights.

**What it does:**
1. What the notebook does
2. Loads the seven field plot boundaries.
3. Loads field-measured L. argenteum heights.
4. Reads the LVIS Level-2 files.
5. Applies waveform quality-control criteria.
6. Filters the LVIS data to the study area.
7. calculates RH98 and associated canopy-height information;
8. extracts LVIS measurements associated with each field plot;
9. summarizes vegetation height within the plots;
10. generates waveform vertical-structure profiles;
11. compares LVIS canopy height against the field measurements;
12. calculates the LiDAR–field validation statistics; and
13. prepares structural information used later in the fusion analysis.

The notebook processes large LVIS files incrementally to avoid loading the entire acquisition into memory at once.
The RH98 analysis should be completed before running the fusion notebook because the later analysis uses the canopy-structure information derived here.

---

### Step 3 — Hyperspectral Classification & Probability Mapping
📁 `Hyperspectral Imaging/03–Phemelo-R_Hyperspectral_Classification.ipynb`
**Kernel: Python**

This notebook performs the main AVIRIS-NG species-classification analysis.

> ⚠️ Generating the probability map tiles for the first time requires downloading and processing all AVIRIS-NG tiles. This can take several hours depending on your machine and internet connection. Completed tiles are cached locally so subsequent runs are fast.

**What it does:**
1. Loads the cleaned spectral library.
2. identifies the spectral bands available in the AVIRIS-NG data;
3. removes noisy wavelength regions and atmospheric water-absorption bands;
4. vector-normalizes the retained spectra;
5. evaluates spectral similarity among the sampled species;
6. calculates pairwise spectral-angle distances;
7. applies principal component analysis to reduce hyperspectral dimensionality;
8. compares six machine-learning classifiers:
    - Logistic Regression
    - k-nearest neighbors
    - Linear Support Vector Machine
    - RBF Support Vector Machine
    - Random Forest
    - XGBoost
9. evaluates classification using stratified cross-validation;
10. calculates target-specific precision, sensitivity, and F1-score;
11. evaluates performance across all sampled species;
12. calculates bootstrap uncertainty for the target classifier;
13. identifies species most commonly confused with L. argenteum;
14. tests the contribution of major spectral regions using wavelength ablation; and
15. reconstructs XGBoost SHAP importance into wavelength space.
**Output:** Probability map GeoTIFFs, all classification figures, and SHAP importance plots
